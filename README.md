# HarvestCustomMapSDK
Custom map SDK Unity Project template and exporter
https://mod.io/g/rr-the-harvest

How to install:
Download the newest Unity Project from Releases. Then open Unity Hub and install the project from disk. The Unity version required is 2022.3.62f2. Floating around the project are text boxes that explain the functionality and usage directions for the Script Wrappers. Examples are found around showing off almost all available functionality.

Everything you need is in the Assets/Harvest+Derived folder. Under CustomMapsData you can find the Scenes folder. EmptyScene.unity is a blank but already set-up scene, a blank canvas ready for you to build off of. The project should, by default, open to TutorialScene1 in the same folder.

Set the name for your map by clicking on the MapRoot object and filling out the parameters in the inspector. These serve no purpose at the moment except for naming the exported zip.
To export a map, navigate to Tools -> HarvestCustom -> Export Map (Android). 
It will be saved as a zip with the name set previously. A file browser will open to ask where to save it.
This can then be uploaded to Mod.io.
